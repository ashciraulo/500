# audio/tyre

Generated by `python3 audio/tools/gen_tyres.py` (deterministic). Mono, 48 kHz OGG Vorbis q6.
**Normalisation:** the three `tyre_roll_dry_*` layers share ONE gain (mid layer ~-20 LUFS, capped so
the fast layer peaks at -1.5 dBTP), so slow < mid < fast is preserved (~-10 dB / 0 / +8 dB): crossfade
them by speed without extra gain. Other loops are at -20 LUFS; one-shots peak at -1 dBTP.
Surface loops (gravel/grass/sand/brick/rumble strip/cat's eyes) are meant to layer over the roll.
