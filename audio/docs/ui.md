# audio/ui

Generated by `python3 audio/tools/gen_ui.py` (deterministic). Stereo, 48 kHz OGG Vorbis q6, peak -1 dBTP.
Style: warm 1970s Italian TV jingle - vibraphone (fundamental + tuned 4th partial, motor tremolo),
soft FM bells, Rhodes-like 1:1 FM electric piano, round bass, felt clicks - in D major (D minor for
'failed'). Everything goes through a tape stage (wow/flutter, soft saturation, ~9 kHz roll-off, faint
hiss) and a small plate-like reverb. None are loops.
